# D18: 研究ポリシー第 4 版の設計（8 通貨の対象系列・評価範囲・前提の記録・比較の前提）

作成日: 2026-11-05
状態: **v0.1 案（2026-11-05。設計役が起草。要決定 D18-1〜D18-5 は回答待ち、仮置き 1〜11 は人間の決定待ち）**

本書は、順 7 の計画書 [D17](D17_step7_eight_pairs_plan.md) の第 4 版レーンの文書 PR **V1**（D17 §2.6、仮置き 4）である。研究ポリシー第 3 版（[D13](D13_research_policy_v3.md)）の評価基準を変えずに、対象系列・評価範囲・前提の記録（basis）・比較の前提（comparison basis）を 8 通貨へ広げる。値は戦略の成績を読まずに、D09 §17.8 の段 1〜5 の規則から機械的に出し、**範囲と値の最終決定は人間が行う**（D17 §0.1 §3 の G3「範囲の決定は人間」）。

凡例: 【事実】は記録・ファイルから読んだこと、【既決】は承認済みの決定、【導出】は既決から一意に出したこと、【提案】は設計役の案（人間の決定待ち）。

**本書で使う言葉**

- **8 通貨**: 順 7 の対象の通貨ペア。USDJPY・EURJPY・GBPJPY・AUDJPY・EURUSD・GBPUSD・AUDUSD・USDCHF（D17 §3 の G2 の 7 通貨＋USDJPY。研究期間の受入れの記録 `docs/data/step7_research_acceptance/README.md` と順 2 の `docs/data/usdjpy_step2_acceptance/README.md` が正本）。`configs/symbols/` にある EURGBP・USDCAD は研究期間の snapshot が無いので対象外。
- **円のペア**: 決済通貨が円の 4 通貨（USDJPY・EURJPY・GBPJPY・AUDJPY）。換算は率 1（恒等）。
- **円以外のペア**: 決済通貨が米ドルの 3 通貨（EURUSD・GBPUSD・AUDUSD。USDJPY 1 本で換算）と、スイスフランの USDCHF（USDCHF の逆数と USDJPY の 2 本で換算）（D06 §19.3）。
- **組**: 時刻の規則の表 版 1 の標準仮説の変換（標準の組 `standard`）と、候補の変換（候補の組 `candidate`）（D12-92 (a)）。
- **前提の記録（basis）**: 範囲を当てた snapshot・対象系列・前提の規則のファイルを研究ポリシーに書いたもの（D13 §6.4）。
- **比較の前提（comparison basis）**: 口座・リスク・費用・数量に効く執行の値を研究ポリシーで固定し、実験設定と読込で照合するもの（D13 §6.6、D13-21 (a)）。

#### D18-3 換算の決め事を比較の前提に入れるか

#### D18-4 6 通貨の実データでの事前の確かめ（run を走らせるか）

問い: 順 7 の主目的「8 通貨のどれでも一巡を回せる」に向けて、機構確認をした EURUSD と USDJPY 以外の 6 通貨（EURJPY・GBPJPY・AUDJPY・GBPUSD・AUDUSD・USDCHF）を、順 8 の研究の前に実データで確かめるか。前提の事実: G4 は 1 通貨（EURUSD）で達成済み（PR #145）。D17-10 で人間は機構確認の通貨を EURUSD 1 つに決めた（USDCHF の 2 本の経路は人工データの受入テストだけで確かめる）。EURUSD の機構確認では、実データで初めて分かった換算の古さの停止が 2 回あった（PR #140・#143）。順 8 で探索の実験が換算の上限で止まると、止まった実行も試行台帳の試行に数えられる（D13 §7.1 の「失敗」）。

| 候補 | 影響 |
|---|---|
| **(a) run は走らせない。価格を読まない「古さとずれの集計」の道具（PR #141 の調査の集計と同じ数え方: 1 分足の記録の有無と時刻だけを読む）を版管理に入れ、円以外の 3 通貨（GBPUSD・AUDUSD・USDCHF）× 2 組に当てて、上限 30 分を超える区間の数と時刻だけを記録する【推奨】** | 機械の時間は数十分。建玉を持っていれば止まりうる区間が分かる（戦略によらない上限側の数）。USDCHF の 2 本の脚のずれも数える。換算の経路のコード（2 本の経路）を実データで通すことはしない（G1 の人工データの受入テストのまま）。円のペアは換算が率 1 なので集計の対象外 |
| (b) (a) に加えて、USDCHF で検証戦略 A・B × 2 組の単一実行と別プロセスの再現を行う（8 本） | 2 本の経路を実データで通せる。機械の時間 約 5.7 時間（M1 の 3 回目の実測 20,654 秒/8 本から）、並列 2 本で壁時計 約 3 時間。戦略の宣言と実験設定（研究ポリシー第 1 版・上限 30 分・第3.2節の費用）を USDCHF 用に 4 本ずつ足す |

## 10. 触れないことと守ること

- 触れないこと（D17 §5.1 のまま）: 判定の規則・閾値・証拠の要件の考え方、新しい研究仮説、新しい部品、並列化（run を 2 本まで並べるのは運用で、機能の追加ではない）、費用・約定モデルの拡張、監視・停止・入替え、封印データの閲覧。
- 守ること（D17 §6 の再掲の当て方のまま）: 戦略の成績を読まない・書かない。価格を作らない・書かない。原データ・snapshot を上書きしない。2024 年以降の封印データを開かない（順 7 の run は研究期間だけ）。値は run の成績を見る前に版管理に固定する。
