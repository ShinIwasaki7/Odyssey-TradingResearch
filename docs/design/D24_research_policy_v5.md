#### D24-3 損失の集中を当てる閾

問い: 損失の集中（最悪の fold の損失 ≤ 経路の純利益の 1.0 倍。決定 136）を当てるのは、経路の純利益が初期資金の 10% 以上のときだけ（D23 の仮置き 22。決定 155 でこのまま）。10% は「損切り 5 回分（1 取引の損失の予算 2% × 5）」とされたが、5 回の根拠は v0.1 の fold の床の推奨（−10%）の導き方で、決定 133（−15%）の後は一意に導けない（第7.3節）。また、本書の起草で次の事実が分かった。

【導出】fold の床（各 fold の損失 ≤ 15%）があるので、経路の純収益率が 15% 以上なら、最悪の fold の損失 ≤ 15% ≤ 経路の純収益率となり、損失の集中は必ず満たされる（どちらも同じ初期資金の口座の率。第3.4節）。したがって損失の集中が判定を変えるのは、経路の純収益率が「閾以上 15% 未満」で、最悪の fold の損失がそれを超えるときだけである。

| 候補 | 影響 |
|---|---|
| **(a) 10% のまま【推奨】** | 集中が効くのは経路の純収益率 10〜15% の間だけ。利益も損失も小さい戦略（純収益率 10% 未満）は集中では落とさず、`PROFIT_FACTOR`・純収益 > 0・fold の床で見る（指示 E「損も小さく済ませられる戦略…は採用したい」） |
| (b) 0%（経路の純利益が正なら常に当てる） | 集中が 0〜15% の間で効く。例の形: 経路の純収益率が小さい正の値で、ある fold の損失がそれを超える戦略を落とす。D23 の仮置き 22 の「代わり: 常に当てる」と同じ |
| (c) 人間が値を指定 | 値しだい。15% 以上を選ぶと集中の条件は判定を変えなくなる |

- 推奨の根拠: 決定 155 で承認された値で、変える新しい根拠は「効く範囲が狭い」という事実だけである。効く範囲が狭いことは、fold の床（決定 133）と集中の倍率（決定 136）の組み合わせから出る帰結で、判定の向き（利益の偏りを許し、損失の偏りを落とす）とは食い違わない。
- 整合: (a) は既決のまま。(b)(c) は D23 の仮置き 22 の改訂を伴う（**既決の改訂を伴う**）。決定 136 の倍率 1.0 はどの候補でも変えない。

- **決定（2026-11-16）: (a)**（推奨。決定 160）。原文は第0.5節。

#### D24-9 負けの取引が無い経路の `PROFIT_FACTOR` の条件の扱い

問い: 経路の取引（完了取引と区間末の仮決済。第3.3節）に負けが 1 件も無いとき（`L = 0`）、`PROFIT_FACTOR` ≥ 1.2 の条件をどう扱うか。D23 §3.1 は「負けが無いのは下限を満たす側と読むのが自然だが、決める」とした。v0.1 は仮置き 4 で「満たす」としたが、設計適合レビューで要決定に上げた。

| 候補 | 影響 |
|---|---|
| **(a) 値なし（`UNDEFINED_DENOMINATOR`。観測不足）として扱い、証拠不足にする【推奨】** | 値なしを成功値に置き換えない規則（D07 §5.1）と、単一の run の #18 の定義（負け無しは値なし）、割り引いた確率の「負けの日が無ければ証拠不足」（第4.5節）とそろう。D09 §7.3 の分け方で `UNDEFINED_DENOMINATOR` は観測不足なので、手順 3 の証拠不足になる（判定できないにはしない）。負け無しの経路は最終検証に進めない。保留の印の扱いは D13 §5.5 の「値なしの場合」と同じ |
| (b) 満たすとみなす（`W ≥ 1.2 × L` の乗算の形で `L = 0` なら満たす） | 負け無しの経路が `PROFIT_FACTOR` で落ちない。値なしの条件を成功の側に読む例外を作る |
| (c) 人間が指定 | 扱いしだい |

- 推奨の根拠: 例外を作らず、既にある値なしの規則と割り引いた確率の扱いにそろう。検証の合計の取引が 8 件以上で負けが 1 件も無い経路は、経路の資産の系列に負けの日がほぼ必ず出るので、多くは割り引いた確率の側でも値を持つが、`PROFIT_FACTOR` だけは観測不足として扱う。
- 整合: (a)(b)(c) とも決定 137（経路で判定に使う）と矛盾しない。(b) は D07 §5.1 の値なしの規則の例外になる。

- **決定（2026-11-16）: (b)**（**推奨と異なる**。決定 166「満たすとみなす」）。原文は第0.5節。帰結: 負けの取引が無い経路は `PROFIT_FACTOR` の条件を満たす（第3.3節・第9.2節・RP5-8・仮置き 4 を (b) で書いた）。証拠の要件（検証の合計の取引 8 件）と経路の純収益率 > 0 は別に効くので、負け無しの経路でも件数が足りなければ証拠不足、純収益が 0 以下なら満たさない。

## 3. 判定の層の定義【提案】

### 3.1 層と式の一覧

各組（標準の組・候補の組）に独立に当て、組の判定（D09 §7.12）は変えない。`I` は実験設定の初期残高（全 run と経路で同じ）。

| **fold の純損失の床** | 各 fold の `R_k` ≥ −0.15。`R_k` は区間末の評価を含む純収益率（第3.2節） | 独立口座の run・検証の区間（端数の fold も同じ値。D13-7 (a)） | 手順 1 |

- **利益の側の条件を置かない**: 新しい条件のどれも、利益の大きさ・偏り・ばらつきを閾にして落とさない（D23 §3.1）。（注: 割り引いた確率の推定量の標準誤差（第4.2節のデルタ法）は、上側も含む日次の収益率の分散 `s_r²` と共分散 `c_rD` にも依る。したがって利益の側のばらつきが大きいと標準誤差を通じて確率は下がりうる。区別して書くと、判定の条件そのもの（比率の分母と閾）は利益の側のばらつきを使わず、ばらつきが効くのは推定の確かさの見積りだけである。）

### 3.2 fold の純損失（区間末の評価を含む値）【提案】（仮置き 2）

- **定義**: `R = (B_end + H − I) ÷ I`。`B_end` は run の台帳の最後の残高（#1 の式の残高）、`H` は `hypothetical_closed`（残った建玉を終わりの価格と費用のモデルで仮に閉じた損益。決済の費用を引いた後。D06 §10.3）、`I` は初期残高。指標集合 v4 の #21（第6節）。
- **なぜ #15 ではないか**【事実】＋【導出】: #15 `NET_RETURN_RATE` は残高の差から作り、run の終わりに残った建玉を含まない（D07 §5.2、D09 §6.4）。区間末に含み損を抱えた fold の損失が床から抜けるので、`H` を足す（D23 §3.2）。
- **なぜ #13 ではないか**【導出】: #13 `END_EQUITY_MTM` は含み込みの資産で、決済の費用を引かない。経路の区間の終わり（方式 (ii)）は費用を引いた後の値を使うと決まっており（D13 の仮置き 28。費用を抜くと 30% の条件の合否が変わりうる、という人間の確認例）、損失の条件も同じ値にそろえる。
- **既決との関係**: #14（`hypothetical_closed` の参考値）は「採否の判断に使わない」（D07 §5.3）。本書は #14 そのものを条件に使わず、残高と足した新しい採用指標 #21 を作る。D07 §5.3 が参考値にした理由（「決済していれば得られたとは限らない」）は、利益の側の値を採否に使う危険の指摘で、損失の床に区間末の含み損を入れる向き（保守的な側）とは別である【導出】。ただし #21 は含み益も同じように入れる（式を対称にし、利益の側だけを抜く規則を作らない）。この点は D07 §5.3 への改訂依頼に書く（第11節）。
- **値なし**: run の終わりの集計が無い（`summaries` が `None`）なら `INPUT_NOT_AVAILABLE`（判定できない。D09 §7.3）。初期残高が 0 なら `UNDEFINED_DENOMINATOR`。建玉が 0 件の run は `H = 0` で値を持つ（観測された事実）。
- **端数の fold**: 期間で換算せず同じ −0.15 を当てる（D13-7 (a)）。

### 3.3 経路の `PROFIT_FACTOR`【提案】（仮置き 4・14）

- **取引の集合**: 経路の各区間の run の完了取引（評価の取引表）と、各区間の終わりに仮に閉じた建玉（`hypothetical_close_lines`。経路の関数が区間の終端の記録に写したもの）。
- **1 件の損益**: 完了取引は取引損益（`trade_profit`。入場の費用込み。D07 §7.3）。仮に閉じた建玉は「仮決済の損益（決済の費用を引いた後）− その建玉の入場の費用」（完了取引と同じ単位にする）。
- **恒等式**: 1 件の損益の和は経路の純損益（最後の区間の終わりの、費用を引いた後の残高 − `I`）に等しい。破れたら構造エラーで止める（仮置き 14。スワップは未計上で、残高を変えるのは取引と費用だけなので、十進数の加減算で厳密に一致する）。
- **判定**: `W = Σ max(0, 損益)`、`L = Σ max(0, −損益)` として、`W ≥ 1.2 × L` なら満たす（乗算の形で比べる）。`L = 0`（負けの取引が無い経路）は満たすとみなす（決定 166。D24-9 (b)）。全件が損益 0 の場合も同じく満たすが、経路の純収益率 > 0 の条件で落ちる。**証拠の要件は別に効く**: 負け無しの経路でも、検証の合計の取引が 8 件に届かなければ手順 3 の証拠不足になる（`PROFIT_FACTOR` の条件の結果は判定の順を変えない）。
- **値なし**: 取引も仮決済も 0 件なら `NO_TRADES`（観測不足）。実際には検証の合計の取引 8 件の要件（手順 3）が先に効く。
- **表示**: `PROFIT_FACTOR` の値（`W ÷ L`。`L = 0` なら「負け取引なし」）、`W`・`L`、件数。単一の run の #18 の定義（負け無しは値なし）は変えない。

### 3.4 損失の集中【提案】（仮置き 3）

- **損失**: 最悪の fold の損失 `Lw = max_k max(0, −R_k)`（`R_k` は検証結果のある fold の #21。率で、口座は独立口座の fold の run）。損失が 0（どの fold も負けていない）なら `Lw = 0`。
- **分母**: 経路の全体の純収益率 `P`（第 4 版の `path.aggregate` の値。区間の終わりの全決済の費用を含む）。fold も経路も初期残高 `I` から始まるので、率の比べ方は金額の比べ方と同じ（`Lw × I ≤ 1.0 × P × I`）。
- **当て方**: `P ≥ 0.10` のときだけ当て、`Lw ≤ 1.0 × P` なら満たす。`P < 0.10` なら「当てない」（`NOT_APPLICABLE`。仮置き 17。理由「経路の純利益が当てる閾に届かない」）。`P ≤ 0` のときは全体の条件で既に満たさないが、集中は「当てない」と記録する。
- **fold の床との関係【導出】**: fold の床で各 `R_k ≥ −0.15` なので、fold の床を満たす実験では `Lw ≤ 0.15`。`P ≥ 0.15` なら集中は必ず満たされる。集中が判定を変えるのは `0.10 ≤ P < 0.15` かつ `Lw > P` のときだけ（D24-3）。
- **値なし**: `P` か、どれかの fold の `R_k` が値なしのときは、その値なしの理由に従う（観測不足なら手順 3、入力が無ければ判定できない）。

### 3.5 近傍の損失の床【提案】（仮置き 5）

- **近傍の定義**: D09 §8 の 2 のまま（1 つの軸だけが 1 段隣。書いた順の直前・直後。端の値は隣が 1 つ）。
- **当てる run**: その fold の**選定の区間**の、近傍の試行の独立口座の run（既にある。新しい run を作らない。検証の区間で隣を走らせない。決定 Q4）。
- **条件**: 近傍の各試行について、最大ドローダウン率 ≤ 0.30 かつ `R`（#21）≥ D24-1 の値。1 つでも割れば、その fold の近傍の床は満たさない。利益の側（近傍も稼ぐこと）は求めない。
- **近傍の区分ごとの扱い**:

| 近傍の試行の区分（D09 §7.4） | 扱い |
|---|---|
| `CANDIDATE`・`EXCLUDED_INELIGIBLE`・`EXCLUDED_METRIC_UNAVAILABLE`（run は完走し、評価も完了している） | 条件を当てる（選定の指標が値なしでも、ドローダウン率と #21 は値を持つ） |

- 判定に使える近傍が 1 つも無い fold（全軸が 1 値、または近傍がすべてコンパイル拒否）は「当てない」（`NOT_APPLICABLE`）と記録・表示する。候補なしの fold は選んだ試行が無いので近傍の床を作らない（D09 §7.3 の fold の判定の手順 1 のまま）。

## 4. 試行数で割り引いた指標【提案】（決定 140。D24-4〜D24-6。仮置き 6〜10）

### 4.1 材料: 下側偏差の比率（D24-4 (a) で書く）

- **日次の収益率**: 経路の資産の系列（D07 §5.6。区間の終わりの費用を引いた後の点を含む）に、#17 と同じ日次の作り方を当てる: `E_0 = I`、`E_k` = k 番目の取引日の終わり以前で最後の資産（無ければ `E_{k−1}`）、`r_k = E_k ÷ E_{k−1} − 1`（`k = 1〜T`。`T` は経路の取引日の数）。
- **平均と下側偏差**: `m = (Σ r_k) ÷ T`、`D_k = min(r_k − τ, 0)²`（`τ` は目標値。(a) なら 0）、`d = √((Σ D_k) ÷ T)`。
- **比率**: `S = m ÷ d`（日次。判定の計算に使う）。表示は年率化 `S × √260`（#17 と同じ係数。指標集合 v4 の #23 と同じ式。第6節）。
- 選定の区間の各試行についても、同じ式を、その試行のその fold の選定の区間の独立口座の run の資産の系列に当てる（`S_{n,k}`。仮置き 7・10）。

### 4.2 推定量のばらつき（デルタ法）

`S` は平均 `μ1 = E[r]` と `μ2 = E[D]` の関数 `S = μ1 ÷ √μ2` なので、日次の観測を独立同分布とみなしたデルタ法（一般の漸近近似）で、推定量の分散を標本の積率から求める。

```
Var(S) ≈ (1/T) × [ s_r² ÷ d² − S × c_rD ÷ d³ + S² × s_D² ÷ (4 × d⁴) ]
```

- `s_r²`・`s_D²` は `r_k`・`D_k` の標本分散（`T − 1` で割る）、`c_rD` は `r_k` と `D_k` の標本共分散（`T − 1` で割る）。`σ = √Var(S)`。
- 積率を標本から取るので、分布の歪み・裾の重さ（高リスクリワードの戦略）が分散に入る。正規分布を仮定した式（シャープ比の Lo の式）を使わない。

### 4.3 割り引き（有効な試行の数と基準値）

- **有効な試行の数**（D24-5）: `M` を試行の数（仮置き 6）、`ρ̄` を試行どうしの平均の相関（D24-5 (a)。0〜1 に切る）として、`N = ρ̄ + (1 − ρ̄) × M`（試行どうしが相関するほど独立な試行が少ない、という割り引いたシャープ比の文献の近似。`1 ≤ N ≤ M`。式は実装 PR 4-2 で出典の式と照合する）。
- **(a) 割り引いたシャープ比の形**（D24-6 (a)）:
  - 基準値 `S* = √V × max(0, Z(N))`、`Z(N) = (1 − γ) × Φ⁻¹(1 − 1/N) + γ × Φ⁻¹(1 − 1/(N × e))`（`N` 個の独立な標準正規の最大の期待値の近似。`γ` はオイラーの定数、`e` はネイピア数、`Φ⁻¹` は標準正規の逆累積分布関数）。`Z(1)` は 0 と定める（`Φ⁻¹(0)` を使わない）。`N` が 1 に近いと `Z(N)` が負になるので 0 で切る（割り引きで基準を緩めない）。`M = 1` なら `S* = 0`（仮置き 6）。
  - `V` は試行どうしの比率のばらつき（仮置き 7）: 各 fold `k` で `S_{n,k}`（値を持つ試行だけ）の標本分散を求め、値を 2 つ以上持つ fold の平均。
  - 確率 `P_d = Φ((S − S*) ÷ σ)`。
  - 参考【事実（数値の確かめ。成績ではない）】: 近似 `Z(N)` は `N` が 3〜6 では真の期待値よりわずかに大きく（基準が厳しい側。例: `N = 4` で近似 約 1.05、真の値 約 1.03）、`N = 2` ではわずかに小さい（近似 約 0.52、真の値 約 0.56）。
- **(b) Šidák の形**（D24-6 (b)。採るなら）: `p = Φ(S ÷ σ)`（経路の比率が 0 を超える確率）、`P_d = p^N`（`= exp(N × ln p)`。`Decimal` の `exp`・`ln` は正しく丸められる）。`V` を使わない。

### 4.4 確率と閾値

- 条件: `P_d ≥ 0.95`（決定 140）。比べるのは十進数（D09 §7.1）。
- 0.95 は証拠の要件の決め方（D13-11 (a)）の水準 95% と同じ（第7節）。
- 正規分布の関数 `Φ`・`Φ⁻¹` は十進数で実装する（仮置き 9）。`Φ(x) = erfc(−x ÷ √2) ÷ 2` を級数と連分数で、`Φ⁻¹` は `Φ` のニュートン法で 28 桁まで求め、既知の値（例: `Φ⁻¹(0.95)`）との照合を単体試験で固定する。

### 4.5 値なし・仮定・適用できない条件

| 状況 | 扱い |
|---|---|
| `T < 2`、または `d = 0`（負けの日が無い） | 経路の比率が値なし（`NO_OBSERVATIONS`／`UNDEFINED_DENOMINATOR`）→ 証拠不足 |
| `σ = 0` | `UNDEFINED_DENOMINATOR` → 証拠不足 |
| `M ≥ 2` で、値を 2 つ以上持つ fold が無く `V` が求まらない（観測不足の試行が多い） | `NO_OBSERVATIONS` → 証拠不足 |
| `M ≥ 2` で、選定の区間の run が失敗した試行のために `V` か `ρ̄` が求まらない | `INPUT_NOT_AVAILABLE` → 判定できない |
| 相関の対の片方の収益率がすべて同じ（分散 0）で相関が定まらない | その対を平均から外し、外した対の数を記録・表示する。全対が外れたら `ρ̄` は値なし（`UNDEFINED_DENOMINATOR`）→ 証拠不足 |
| `M = 1` | `S* = 0`（割り引かない）。`V`・`ρ̄` は要らない |

- **仮定**（レポートの脚注に定型で出す。D13 §5.3 の流儀）: 日次の収益率が独立同分布（自己相関があると `σ` を過小に見積もる）、選定の区間での試行どうしのばらつきと相関が、選んだ試行の経路にも当てはまる、`Z(N)` は独立な試行の最大の近似。
- **適用が弱くなる条件**: 取引が少なく大半の日が建玉なし（収益率 0）だと、下側偏差の観測が少なく `σ` が大きい（確率が下がる。証拠の少なさが確率に出る向きで、満たしにくくなる）。
- **台帳の累計を使わない**（決定 Q17、D23 の仮置き 8）。

### 7.2 近傍の純損失の床（D24-1）

- 【導出】fold の床 −0.15 は検証の区間 364 日の値。近傍は選定の区間 728 日に当てる。同じ損失の速さ（1 年あたり 15%）を 2 倍の長さに比例させると −0.30。複利で延ばすと `1 − 0.85² ≒ 0.2775` で −0.2775。どちらも方針の値（決定 133）と区間の長さだけで決まる。全 fold の選定の区間は 728 日（端数の fold を含む）なので値は 1 つ。
- 【導出】選定の区間の独立口座の run で、最大ドローダウン率（含み込み、ピーク基準）≤ 0.30 なら、最高値は初期残高以上なので、終わりの含み込みの資産は初期残高の 0.70 倍以上で、含み込みの純収益率は −0.30 以上。#21 は含み込みの資産から決済の費用を引いた値なので、−0.30 の床がドローダウンの床と別に落とすのは、終わりに残った建玉の決済の費用でその境を下回る近傍だけである。−0.15 を選ぶと、ドローダウンの床と独立に効く。

### 7.3 損失の集中を当てる閾（D24-3）

- 【事実】D23 の仮置き 22 の理由は「10% は損切り 5 回分（2% × 5）」。5 回は、v0.1 の fold の床の推奨（年 3〜4 回の取引がすべて損切りで 6〜8%、余白 1 回分を足して 5 回分 = −10%）の導き方から来ている（D23 §3.6）。決定 133 で fold の床は −15%（7.5 回分）になった。
- 【導出】閾を fold の床から導くと、15%（fold の床と同じ）では集中の条件が判定を一度も変えない（第3.4節）。それより小さい値のどれを選ぶかは、方針の値から一意に決まらない。したがって 10% は**仮定**であり、D24-3 で人間が確かめる。
- 【導出】集中の条件が効く範囲は、経路の純収益率が「閾以上 15% 未満」で、最悪の fold の損失がそれを超えるときだけ。

### 7.4 `PROFIT_FACTOR` の下限（D24-2）

- 導出の試み: (1) 費用の比から: 第 4 版の費用（スプレッド・滑り・手数料）と 1 取引の損失の予算 2% の比は、戦略ごとの損切りの幅で決まり、全戦略に共通の値にならない（費用の値は価格の単位なので本書に書かない）。(2) スワップの余白から: 未計上で、大きさを方針の値から出せない。(3) 証拠の件数から: `PROFIT_FACTOR` の推定の幅は取引の損益の分布で決まり、成績を見ずに値を出せない。
- 結論: **導出できない**。1.2 は「勝ちの合計が負けの合計を 2 割上回ることを、未計上の費用への余白として求める」という方針の仮定（D23 §3.6）。D24-2 (a) なら、研究ポリシーのファイルの注記に「1.2 は方針の仮定の値で、導出したものではない」と書く。
