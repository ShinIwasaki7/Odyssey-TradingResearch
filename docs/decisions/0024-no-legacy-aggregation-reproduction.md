# ADR-0024: 上位足の集約は新規則のみとし、旧集約の再現版は作らない

- 状態: 承認（2026-09-20）
- 決定者: ユーザー
- 関連: [全体計画書](../design/fx_research_platform_overall_plan.md) 第6節 C-4、[D03](../design/D03_marketdata_and_time.md) §5、上位設計書 §3.2〜3.3

## 文脈

上位設計書は「既存の集約方法を検証用に再現した後、新しい足生成規則へ変更する場合は別バージョンとする」としていた。しかし旧基盤の集約出力（4h・1d の生成結果）は本リポジトリに引き渡されておらず、再現版を作っても照合する対象が存在しない。

## 決定

- 1h → 4h / 1d の集約は、ニューヨーク現地 17 時を基準にした新規則（D03 §5.1、規則 ID `ny17_v2`）だけを実装する。
- `bar_start` は区間の開始とし、旧基盤の「最初の観測時刻ラベル」は採用しない。
- 旧集約の再現版は作らない。将来、旧基盤の集約出力が入手できた場合は、別版の集約規則として追加し、本 ADR を改訂する。

## 影響

- 旧基盤の結果との数値照合は行えない。新基盤の集約は、構成足からの再計算との一致（プロパティテスト）と人工データの固定出力（golden）で検証する。
- snapshot manifest の `conversion` に集約規則の版 `ny17_v2` を記録する。
