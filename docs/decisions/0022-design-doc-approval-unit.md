# ADR-0022: 設計文書は1文書ずつ承認する

- 状態: 承認（2026-09-19）
- 決定者: ユーザー
- 関連: [全体計画書](../design/fx_research_platform_overall_plan.md) 第6節 D-1

## 文脈

段階0では複数の設計文書（D02〜D08）を書く。まとめて承認すると、未確定部分が承認済み部分に紛れる。

## 決定

- 設計文書は1文書ずつ承認する。
- 複数文書の並行執筆は可能だが（例: D02 と D03）、承認は個別に行う。
- 各文書は内部で「確定／案／要決定」を区別し、要決定が残る場合はその部分を除いた範囲で承認を得る。

## 影響

- 実装開始条件（ADR-0016）の判定は文書単位で行う。
