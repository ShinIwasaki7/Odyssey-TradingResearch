# ADR-0007: エンジンは単一スレッドのイベント駆動参照実装を先に作る

- 状態: 承認（2026-09-18）
- 決定者: ユーザー
- 関連: [全体計画書](../design/fx_research_platform_overall_plan.md) 第6節 A-7

## 文脈

WAIT・追い越し・フェーズ順序はイベント意味論で定義されており、上位文書は「因果関係の契約を先に固める」としている。

## 決定

単一スレッドのイベント駆動参照実装を先に作る。決定論的な優先キューで処理し、非同期メッセージ基盤は使わない。

## 影響

- 高速化版（ベクトル化等）は、参照実装との同値性検証を条件に後から加える。
- 優先キューの順序キーは D06 で確定する。
