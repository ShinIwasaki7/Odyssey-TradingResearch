# ADR-0029: swap / rollover は初版で未計上とし、結果に明記する

- 状態: 承認（2026-09-20）
- 決定者: ユーザー（リポジトリ所有者）
- 関連: [全体計画書](../design/fx_research_platform_overall_plan.md) 第6節 C-5・第7.4節（D06）

## 文脈

ポジションの持ち越し（rollover）に伴う swap コストをどう扱うかが未決定だった（要決定 C-5）。全体計画書は「政策金利差を実 swap と同一視しない」ことを既に合意済みとした上で、初版では未計上とし、その旨を結果に明記する案を推奨していた。決定時期は段階2（D06 の確定時）としていたが、他の選択肢が挙がっておらず、推奨案のまま人間が承認した。

## 決定

- 初版のバックテストでは swap / rollover コストを計上しない。
- 未計上であることを、バックテスト結果（result）に明示的に記録する。政策金利差など代理指標での近似も行わない。
- 将来 swap を計上する場合は、本決定を改訂する別途の ADR と設計変更を要する。

## 影響

- D06（バックテストエンジン設計）の `CostModel` は、手数料・slippage・spread のみを扱い、swap を対象外として明記する。
- D07（単一実行評価設計）の指標・レポートは、swap 未計上である旨をユーザーに伝わる形で出力に含める。
- 実 swap を用いた検証（クロスチェック）は初版の範囲外となる。
