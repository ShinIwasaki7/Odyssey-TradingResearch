# ADR-0023: ADR は1決定1ファイルで、必須項目と廃止規則を持つ

- 状態: 承認（2026-09-19）
- 決定者: ユーザー
- 関連: [全体計画書](../design/fx_research_platform_overall_plan.md) 第6節 D-4

## 文脈

決定記録の形式を仮置きで運用してきた（ADR-0001〜0021）。正式な形式を確定する。

## 決定

- 1決定1ファイル。ファイル名は `NNNN-<slug>.md`。
- 状態は 提案 / 承認 / 廃止 の3つ。
- 各 ADR は次を持つ: 状態、日付、決定者、文脈、決定、影響、関連文書。
- 廃止時は後継 ADR への参照を必須にする。
- 索引は `docs/decisions/README.md` に保持する。

## 影響

- 既存の ADR-0001〜0021 のうち文脈または影響を欠くものは本形式に揃えた。
- 依存規則・パッケージ構成の変更は D01 第12節に従い ADR を伴う。
