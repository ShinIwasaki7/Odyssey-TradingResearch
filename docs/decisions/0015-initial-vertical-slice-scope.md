# ADR-0015: 初版の縦断実行範囲は USDJPY・JPY 口座・判断 1h・執行 15m

- 状態: 承認（2026-09-18）
- 決定者: ユーザー
- 関連: [全体計画書](../design/fx_research_platform_overall_plan.md) 第6節 C-3

## 文脈

上位文書の数値例は USDJPY・JPY 口座で書かれており、縦断実装の検証対象を1ペアに絞ると契約の抜けを早く見つけられる。

## 決定

初版の縦断実行範囲は USDJPY 単一、口座通貨 JPY、判断系列 1h（日足は 1h から生成）、執行系列 15m とする。

## 影響

- 移管済みの他9ペアは削除せず、保管・受入れ能力は残す。
- 他ペア・複数建玉への拡張は段階6。
