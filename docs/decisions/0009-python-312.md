# ADR-0009: Python は 3.12 系に固定する

- 状態: 承認（2026-09-18）
- 決定者: ユーザー
- 関連: [全体計画書](../design/fx_research_platform_overall_plan.md) 第6節 B-1

## 文脈

シェル既定の python3 は 3.8.8 / 3.9.5 で標準機能が不足する。uv 管理の 3.12.13 が利用可能。

## 決定

- `requires-python = ">=3.12,<3.13"`
- `.python-version` は 3.12.13 に固定。

## 影響

- 3.13 への更新は、依存ライブラリと golden trace を検証した別変更にする。
- 実行は `uv run` 経由に統一する。
