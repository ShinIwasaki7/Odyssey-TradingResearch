# 研究期間の 7 通貨の受入れ（取得日 2026-10-16）— 分類の確認と snapshot の承認の材料

研究期間（2017〜2023 年）の OANDA MT5 API の 1 分足のうち、USDJPY を除く 7 通貨を、時刻の変換の組ごとに 1 つずつ（7 通貨 × 2 組 = 14 個）
snapshot（受け入れたデータの固定した版）にし、分類・確定・承認した記録。§1〜§7 は暫定の段階（分類と承認の前）の値、§10・§11 が確定と承認の記録。手順は D03 §17.8（USDJPY の順 2 の D12 §12.4 と同じ）。

- **この一覧は人間の確認の材料**（D03 §17.10 の質問 1「分類の確認」と、その後の質問 2「snapshot の承認」）。質問 1 は 2026-11-04 に人間が「7 通貨ともこの分類で確定（推奨）」と回答し（原文は `human_decision_2026-11-04_classification.md`）、14 個の分類と確定（`data classify`）を行った（§10）。質問 2 は 2026-11-04 に人間が「7 通貨すべて承認（推奨）」と回答し（原文は `human_decision_2026-11-04_approval.md`）、14 個に承認を記入した（§11）。§1〜§7 は確定の前（暫定の段階）の値のまま。
- 書いてあるのは件数・時刻・区間・ハッシュ・合否だけ。価格・足の中身・戦略の成績は読んでも書いてもいない。2024 年以降の封印のデータ（`data/raw/oanda_mt5_sealed/`）と旧データ（`data/raw/market/`）は開いていない。
- 原ファイルは読むだけで変えていない（受入れの前後で 7 通貨 × 84 = 588 ファイルの SHA-256・サイズ・更新時刻が同じ。§7）。
- 言葉: **標準の組・候補の組** = 時刻の規則の表 版 1 の標準仮説だけの変換（`standard`）と、候補を持つ行を候補の変換に替えた組（`candidate`）（D12-92 (a)）。**休場帯の足**（`UNEXPECTED_BAR`）= カレンダーが休場とする時間帯にある 1 分足で、人間の分類が要る警告。**カレンダーの外の足**（`CANDIDATE_OUT_OF_CALENDAR`）= 候補の組でカレンダーの外に出た 1 分足で、分類の対象ではなく件数だけを記録する（D12-97 (a)）。**partition** = snapshot の中の系列ごとの区切り（研究期間は系列ごとに 1 つ、区分は研究履歴 `RESEARCH_HISTORY`）。
