### 1.4 探索する軸とその理由（D14-2 (a)。値の正本は D14 §4.3、理由は D14 §4.1）

| 軸 | 戦略宣言の使用箇所とパラメータ | 値（書いた順） |
|---|---|---|
| 1 時間足の EMA の期間 P | `h1_ema.period` | 20, 50 |
| 利確の倍率 R | `take_profit.reward_risk` | 1.5, 3.0 |

- 4 試行（2 軸 × 2 値）。試行番号は D09 §5.2 の列挙の順（軸は `(instance, parameter)` の昇順で、後ろの軸ほど速く変わる）: 0 = (P 20, R 1.5)、1 = (P 20, R 3.0)、2 = (P 50, R 1.5)、3 = (P 50, R 3.0)。この順は選定の同点の解き方も決める。
- 1 時間足の EMA の窓 `window_bars` は格子の最大の P の 3 倍の 150 に固定する（D14 仮置き 15。部品の条件 `window_bars ≥ 2 × period` を全試行で満たし、検証戦略 B の 15 分足の EMA（期間 20・窓 60）と同じ比）。
- 理由: 試行の上限（1 実験 100）より十分小さくし（初回から上限を使い切らない。D13 §0.1）、選定区間で偶然よい試行を選ぶ偏りを小さく保ち、原因分析で軸ごとに「上げると良くなるか悪くなるか」を読める最小の格子にした。P は検証戦略 B の 15 分足の EMA の期間 20 を下端に置き、R は検証戦略 A の固定値 2.0 の前後に置いた。1 実験が夜間 1 回強に収まる大きさ（D14 §8.2 の見積り）。値は結果を見て選んでいない。

### 1.6 研究仮説を選ぶ前の閲覧の確認の結果と、その影響（D14-1 の前提の確認。D14 §3.3 を写した。数値は書かない）

- **確認の結果（事実。2026-10-22。原文は D14 §0.5）**: **人間が、順 3 の検証戦略 A・B の単一実行のレポートの要約（指標の一覧）を見た後に、仮説 H2 を選んだ**。設計役の候補（D14 §3.2）は成績を見ずに作った。H2 は検証戦略 B の市場状態の部品と検証戦略 A の出口から成る。
- **この事実の意味**: 「研究仮説を成績を見ずに選んだ」という前提は**満たされない**。順 3 の単一実行は評価範囲を含む全区間（全 fold の検証区間を含む）を走らせたので、H2 は、その期間での関連する戦略の成績の要約を見た後に選んだ仮説である。
- **影響と扱い**:
  1. **元の実験（版 1）の判定も、独立した確認として扱わない。版 1 の判定も、検証区間を含む期間の関連する成績の要約を見た後に選んだ仮説の判定であり、独立した確認ではない**（人の手の注記。D14 §3.3 の影響 1）。台帳の系譜から機械的に付く「独立した確認ではない」の注記（D13 §7.3）は、順 3 の単一実行が台帳に書かれない（D09 §10.10「書く対象: 探索の実験だけ」）ので、版 1 のレポートには**自動では付かない**。そのため、ここと一巡の報告（D14 §7.1）に人の手で書く。
  2. **台帳の累計には入らない**: 「同じ検証区間を見た先行の実行」の数え方（D09 §10.10 の (a)）は探索の実験の行だけを数えるので、この閲覧は累計に現れない。累計を読むとき（採用審査など。順 6）に、この閲覧が数に入っていないことを一巡の報告に書く。
  3. 判定の規則・研究ポリシー・台帳の形式は変えない（既決のまま。注記は記録の追加だけ）。
