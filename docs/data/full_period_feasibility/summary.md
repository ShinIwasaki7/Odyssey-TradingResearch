# 全期間のデータ上の実行可能性 — 最終集計（8 通貨 × 2017〜2023）

人間の指示（2026-10-17）の「B. 全期間のデータ上の実行可能性の検証」の結果。数え方は設計 PR #84 で確定した規則ファイル（数え方の規則 版 1・時刻の規則の表 版 1・カレンダー `fx_ny17_oanda` 版 1）から読んだ。

- **これは「データ上の実行可能性」の集計で、エンジンの正常動作や実際の市場での約定の再現性は確かめていない。**
- 価格は読んでいない・載せていない（件数・時刻・被覆率・ハッシュだけ）。戦略の成績は読んでいない。2024 年以降は参照していない。原データは変えていない。

- 組 `standard` は時刻の規則の表の標準仮説、`candidate` は候補を持つ行をすべて候補の変換に替えた組（感度の検証。D12-92 (a)）。
