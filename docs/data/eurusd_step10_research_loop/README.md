### 1.2 研究仮説（決定 122 の H7。D22 §7.1.2）

人間の決定 122（2026-11-11 16 時 30 分台 JST。要決定 D22-10。推奨を付けずに問うた）の回答の原文: 「H7：1 時間足の 2 本の移動平均の交差」

> EURUSD の 1 時間足の EMA（期間 20）が 1 時間足の EMA（期間 S）を上抜けたら成行で買い、直近 20 本の 1 時間足の確定安値に損切り、損切りの幅の R 倍に利確を置く規則は、費用を引いた後も、両組で共通基準を満たす

- 「EMA」は指数移動平均（直近の足ほど重く平均した値。部品 `ema`）。「上抜け」は部品 `breakout_trigger` の規則で、比べる 2 つの値（ここでは短い EMA と長い EMA）が「上回っていない」から「上回る」に変わった評価でだけ取引機会を 1 つ出す（`EDGE`。D05 §4.3 の (2)）。
- 買いだけ（片方向）。売りの対称版は別の仮説として扱う（D22 §7.1.1 の条件 5）。
- 部品の組み合わせ（D22 §7.1.2 の H7 の列）: 局面なし。取引機会は `ema` v1 を 2 つ（短い側 `fast_ema`・長い側 `slow_ema`。どちらも 1 時間足の終値、1 時間足の確定で評価）と `breakout_trigger` v1（価格 = `fast_ema` の出力、水準 = `slow_ema` の出力、`LONG`、1 時間足の確定で評価）。出口は `market_order_intent` v1・`extreme_price` v1（`MIN`、1 時間足の安値）・`level_stop_loss` v1・`fixed_rr_take_profit` v1（検証戦略 A と同じ）。即時の入場（`IMMEDIATE`）。使用箇所は 7。
- 取引機会の有効性の束縛は空（確認待ちが無いので再検査の時点が無い。A と同じ）。同時の保持は 1（`max_active=1`・`KEEP_EXISTING`・`KEEP_OTHERS`。A・B・H2・H6 と同じ）。
- 履歴窓の最大は 1 時間足 300 本（約 12.5 日。日足 60 本より十分短い。D22 §7.1.1 の条件 3）。
- 既出の仮説（H1〜H6）との違い（D22 §7.1.2）: 取引機会を「価格と水準」でなく「2 本の EMA どうし」の上抜けで作る。H2 は 1 時間足の終値が 1 本の EMA を上抜ける形で日足の局面を持つが、H7 は局面なし。H1〜H6 に EMA どうしを比べる取引機会は無い（決定 116「同じ規則は出さない」）。
